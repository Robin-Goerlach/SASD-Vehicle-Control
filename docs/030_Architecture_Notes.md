# Architekturhinweise

Das Projekt soll als eigenständiges Repository starten, aber als Schwesterprojekt von SASD Finance Control entworfen werden.

## Empfohlene Schichten

- App/UI: Darstellung und Benutzerinteraktion
- Application: Use Cases und Anwendungsdienste
- Domain: Fachmodell und Regeln
- Infrastructure: SQLite, Dateispeicher, Export, Backup

## Gemeinsame spätere Bausteine mit Finance Control

- Dokumentenarchiv
- SHA256-Hashing
- Audit-Log
- Lieferanten/Stammdaten
- Verträge
- Reporting
- Backup/Restore
