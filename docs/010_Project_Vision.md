# SASD Vehicle Control – Projektvision

SASD Vehicle Control soll eine lokale KFZ-Verwaltung werden, die Fahrzeugdaten, Tankbelege, Wartungen, Reparaturen, Dokumente und Kosten nachvollziehbar zusammenführt.

Der fachliche Schwerpunkt liegt auf vertrauenswürdiger Dokumentation statt auf Live-Tracking. Die Anwendung soll besonders für kleine Firmen, Selbständige und technisch orientierte Privatanwender geeignet sein.

## Leitprinzipien

- lokal nutzbar
- dokumentenorientiert
- revisionsnah vorbereitet
- keine stille Datenlöschung
- klare Trennung von Domain, Application, Infrastructure und UI
- spätere Integration mit SASD Finance Control
